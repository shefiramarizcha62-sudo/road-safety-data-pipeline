# Road Safety Data Pipeline

A Big Data project implementing an Apache Spark-based data pipeline to analyze historical traffic accident data using Descriptive Analytics.

## Project Overview

This project aims to process and analyze traffic accident data through a series of Big Data pipeline stages, starting from data ingestion, data cleaning, data storage, data aggregation, and data visualization.

The project uses Apache Spark (PySpark) in Google Colab to demonstrate data processing and generate meaningful insights from historical traffic accident records.

## Objectives

- Implement a data processing pipeline using Apache Spark.
- Identify and handle duplicate, missing, and inconsistent data.
- Standardize and validate the dataset.
- Compare CSV and Parquet storage formats.
- Analyze traffic accident patterns through data aggregation.
- Present analytical findings through data visualization.

## Analytics Approach

Descriptive Analytics — analyzing historical traffic accident data to understand patterns, distributions, and trends.
